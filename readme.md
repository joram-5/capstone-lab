# Planet Facts

A search page that shows facts about the planets of our solar system. Type a planet name, and the page shows its picture and key details. It was built from a Figma design as part of my capstone projects at TSAcademy.

## Features

- Search for a planet by name (Mercury to Pluto)
- A planet card showing the type, description, gravity, mass, period, temperature, moons, diameter and distance from the Sun
- A "No results found" card when the search does not match any planet
- A comparison table of the planets, filled in with JavaScript
- Dark and light mode, with your choice saved in the browser

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Structure

- `index.html` is the page structure
- `style.css` is the styling
- `script.js` holds the planet data and the search, table and theme logic
- `images/` holds the planet pictures and icons

## How to Run

1. Download or clone this repository.
2. Open the `index.html` file in your browser.
